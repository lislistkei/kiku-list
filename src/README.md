## ファイル
- works.txt / trivia.txt / videos.tsv … クラシックの曲・豆知識・動画
- opera_works.txt / opera_videos.tsv … オペラの名場面（豆知識つき）と動画
- rewrite/points.json … 聴きどころ（情景たっぷり版。works の聴きどころを上書きする）
- lyrics/part1〜5.json … オペラの歌詞の全文訳（Claude が原語の台本から訳したもの。122曲）。key → {lang, t（訳文）, note}
- lyrics/bi1〜5.json … 対訳（原文1行と訳1行の組 [原文, 訳]。【役名】だけの組は歌い手、["",""] は段落の区切り）。これがある曲は全文訳の代わりに対訳を出す。原文は Claude が覚えている台本から書いたもので、印刷の台本とは照らしていない。「（原文不確か）」は自信がない行。イェヌーファは原文なし
- lyrics/gist.json … 歌詞の著作権が残る3曲（ジャンニ・スキッキ、サマータイム、夕鶴）の大意だけ
- about/o1〜2.json（オペラ）・c1〜5.json（クラシック） … 作品ごとの説明。「作曲家|作品名」→ {y: 年・幕や楽章の数などの1行, s: 本文}。カードの「作品について」に出る。Claude が書いたもので、資料とは照らしていない（自信のないことは書かない方針）
  - 序曲・間奏曲など歌のない曲には訳はつけない。カラス・三大テノール・パヴァロッティの曲は、同じ曲の訳を使う（opera_gen.py）
  - 訳の中の「（このあたりは大意）」は、原文の細かい言い回しに自信がない部分
- wind_works.txt / wind_videos.tsv … 吹奏楽の曲（153曲・うちマーチ70曲。2026/11/10 に95曲から増やした）と動画。1行＝key|作曲家|曲名|ここを聴く|検索語|長さ|聴きどころ|豆知識
  - 日本の課題曲・作曲者名・年は、YouTube の動画タイトルや説明文で確かめてから書いた（記憶だけで書くとまちがえやすい）
  - 動画は公式の楽団（米海兵隊バンド・東京佼成WO・自衛隊や海上保安庁の音楽隊・洗足学園など）を優先。153本すべて埋めこみ可を確認ずみ（2026/11/10）
- about/w_src.py → about/w1.json … 吹奏楽の「作品について」（python about/w_src.py で作る。自信のない年は書かない）
- mw_works.txt / mw_videos.tsv … マーチとワルツ版で新しく足した曲（81曲。2026/11/10〜11）。形は wind_works.txt と同じ
- mw_gen.py … マーチとワルツ版（march-waltz/）を作る。クラシック・オペラ・吹奏楽の3ページの HTML から曲を借りてきて（c:・o:・w: をつけたキー）、新しい曲と合わせる。だから gen.py・opera_gen.py・wind_gen.py のあとに実行する
  - 新しい曲の動画は YouTube の検索で探し、埋めこみ可（oembed で確認）のものを、公式の楽団・レーベルを優先して選んだ
- page_template.html … ページのひな形（目次・好き嫌い・おすすめ・埋めこみ再生）
- gen.py / opera_gen.py / wind_gen.py … Claudeのページ用 HTML を作る
- make_site.py … 公開用（site/）の HTML を作る

## 作り直し方
src の中身を1つのフォルダに置き、`python gen.py` → `python opera_gen.py` → `python wind_gen.py` → `python mw_gen.py` → `python make_site.py` の順に実行。
できた site/ の中身（index.html, classical/, opera/, wind/, march-waltz/）をこのリポジトリに入れて push する。

- 2026/11/19：page_template.html に3つを足した（親の会話「機能おためしツアー」の改良案から）
  - **今日の1曲**：ページの頭（曲数の下）。そのページの曲から、日付で1曲を決める（その日のうちは同じ曲）。「聴きどころを読む」で #k-キー のカードへ飛ぶ。4ジャンル全体からにしなかったのは、各ページが自分の曲のデータしか持っておらず、ほかのページの曲を出すにはデータを重ねて持つ必要があるため
  - **「聴いた」ボタン**：各カードの好き嫌いの上。押すと今日の日付で記録、同じ日にもう一度押すと取り消し。前に聴いた日と回数も出る
  - **聴いた記録**：今日の1曲の下（たためる欄）。今月聴いた曲の数・この1週間の7つの丸・一覧（新しい順）。保存は localStorage の `listened-v1`（4ページは同じサイトなので、記録は4ページ共通。一覧からほかのページの曲へも飛べる）
  - ほかのページへのリンク用に、make_site.py が DATA に "page"（フォルダ名）を入れている
- 2026/11/19：**デザインを「劇場のプログラム冊子」に作り直し**（のんさんが3案から「案2」を選んだ。見比べページ https://claude.ai/artifact/2dUBWeRaopGvH1RQnu3N77 ）
  - 1ページの中を3つの画面に分けた：表紙（本日の演目・目次・さがす・聴いた記録・次に聴くなら）／章の曲目（#章のid）／1曲のページ（#k-キー）。前は全部の曲がカードで縦に並び、スマホで「ごちゃごちゃ・曲が出るまで遠い」と言われていた
  - 見た目：クリーム色の紙・明朝（しっぽり明朝）・欧文は Cormorant Garamond・赤（#a8322b）と金の線。ダークモードは「夜の冊子」（こげ茶の紙に金）
  - 絵：曲ごとの線画の額（page_template.html の motifOf）。曲名のことば（星・月・海・森・ミサ・王・ワルツ…）で絵がらを選び、合わなければキーから決まった絵がら。絵文字は使わない
  - 「聴いた」はハンコ（押すと赤い判、もう一度で取り消し）、聴いた記録は半券。保存先（listened-v1・ratings-v1・play-mode-v1・embed-blocked-v1）は前と同じなので、前の記録はそのまま使える
  - #k-キー のリンク（教本から）は、1曲のページが開く。キーの名前は変えないこと
  - オペラの場面（作品名が『』のもの）は、場面の名前を大きく、作曲家と作品を上に小さく出す
  - 表紙（make_site.py）は4ジャンル全体から今日の1曲を出す（4ページの曲を ALL として表紙に持たせた）
